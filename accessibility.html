Accessibility statement

We want everyone to be able to use this website. As an accessibility consultancy, we hold ourselves to the same standard we recommend to our clients.

Conformance status

This website aims to conform to the Web Content Accessibility Guidelines (WCAG) 2.2 at level AA, and to level AAA where practical.

What we've done

  • Semantic HTML with landmarks, a logical heading structure and a skip link.
  • Text and interface colours that meet at least WCAG AA contrast, in both light and dark mode.
  • A clearly visible focus indicator for keyboard users.
  • Content that reflows to 400% zoom and works in portrait and landscape.
  • Respect for your reduced-motion and high-contrast (forced colours) settings.
  • Form fields with visible labels, autocomplete and clear error messages.
  • The Atkinson Hyperlegible typeface, designed for readers with low vision.
  • Everything works without JavaScript.

How we tested

This site was last tested on 26 October 2026 using:

  • NVDA with Firefox and Chrome on Windows
  • VoiceOver with Safari on macOS and iOS
  • TalkBack with Chrome on Android
  • Keyboard only, browser zoom up to 400% and Windows High Contrast
  • Automated checks with axe DevTools and Lighthouse

Known limitations

We are not currently aware of any accessibility barriers on this website. If you find one, please let us know.

Feedback

If you have trouble using any part of this site, email hello@example.com. We aim to respond within two working days.
